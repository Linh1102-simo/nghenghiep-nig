# Định hướng nghề nghiệp

Website tĩnh HTML/CSS/JavaScript, trắc nghiệm Holland RIASEC gồm 30 câu.
Không cần backend hoặc biến môi trường.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Triển khai Vercel
1. Tạo repository mới trên GitHub, ví dụ `dinhhuongnghenghiep`.
2. Upload 3 file `index.html`, `style.css`, `script.js` (có thể upload README).
3. Vào https://vercel.com/new và import repository.
4. Vercel tự nhận diện website tĩnh. Nếu cần, chọn Other; Build Command để trống; Output Directory để `.`.
5. Nhấn Deploy.

Tên project Vercel nên dùng `dinhhuongnghenghiep-nig` vì tên project/subdomain không hỗ trợ dấu chấm ở giữa như tên bạn nhập.
Sau khi deploy, địa chỉ thường có dạng `https://dinhhuongnghenghiep-nig.vercel.app`.

Muốn dùng tên miền riêng `dinhhuongnghenghiep.nig`, bạn cần sở hữu/đăng ký tên miền `.nig` và thêm trong Project > Settings > Domains. Nếu `.nig` không phải tên miền đã đăng ký/hỗ trợ, hãy chọn tên miền hợp lệ khác.
